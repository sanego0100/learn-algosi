# Определение

Пузырьковая сортировка выполняет несколько проходов по массиву, сравнивая соседние элементы и перемещая большие элементы вправо (или меньшие влево), пока массив не станет отсортированным.

```python
def bubble(arr):
    n = len(arr)
    for i in range(n):
        for j in range(n-1):
            if arr[j] > arr[j+1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]
    return arr

```

В цикле `for` существует другой цикл `for` в котором проверяется условие `if` если элемент массива(`arr[j]`)  больше аргумента больше соседнего элемента(`arr[j+1]`) то элементы меняются местами (`arr[j],arr[j+1]=arr[j+1],arr[j]`). Т.e. место памяти (на который указывает индекс массива) будет хранить другое значение

## Реализация на Rust

```rust
fn bubble(arr: &mut [i32]) {
    let n = arr.len();
    for i in 0..n {
        for j in 0..n - 1 {
            if arr[j] > arr[j + 1] {
                arr.swap(j, j + 1);
            }
        }
    }
}

fn main() {
    let mut arr = vec![14, 12, 23, 5, 61, 1, 2, 45, 65];
    bubble(&mut arr);
    println!("{:?}", arr);
}

```

Здесь нету `return` потому-что значение уже изменено по ссылке после вызова функции
