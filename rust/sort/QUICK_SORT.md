# Определение

Быстрая сортировка работает по приципу "разделяй и властвуй", массив делится на две части  (less than pivot and more than pivot) по опорному элементу (pivot)

```python
import random
def quicksort(arr):
    if len(arr)<=1:
        return arr
    else :
        pivot=random.choice(arr)
        left = [ i for i in arr if i<pivot]
        mid = [ f for f in arr if f==pivot]
        right = [ x for x  in arr if x>pivot]

        return quicksort(left)+mid+quicksort(right)

numbers=[1,23,334,4511,67,23]
mass=quicksort(numbers)
print(mass)
```

Cначало проверка `if len(arr)<=1`, потому-что сортировать массив из одного элемента бессмысленного и увеличит кол-во обращений к процессору/памяти.

Далее создается опорный элемент `pivot` (`random.choice(arr)`, чтобы был выбран случайный элемент, это нужно для избежания неудачного `pivot`(в случае плохого `pivot` алгоритм деградирует до скорости O($n^{2}$) ) )

Внутри массивов `left`, `mid`, `right` сортируются элементы по `pivot`

Завершающий этап в `return` объединяются все массивы

-----------
## Реализация на Rust

```rust
fn quick_sort(arr: &mut [i32]) {
    let len = arr.len();

    if len <= 1 {
        return;
    }

    let pivot = partition(arr);

    quick_sort(&mut arr[..pivot]);
    quick_sort(&mut arr[pivot + 1..]);
}

fn partition(arr: &mut [i32]) -> usize {
    let len = arr.len();

    let pivot_index = median_of_three(arr);

    arr.swap(pivot_index, len - 1);

    let pivot = arr[len - 1];

    let mut i = 0;

    for j in 0..len - 1 {
        if arr[j] < pivot {
            arr.swap(i, j);
            i += 1;
        }
    }

    arr.swap(i, len - 1);

    i
}

fn median_of_three(arr: &[i32]) -> usize {
    let first = 0;
    let middle = arr.len() / 2;
    let last = arr.len() - 1;

    let a = arr[first];
    let b = arr[middle];
    let c = arr[last];

    if (a <= b && b <= c) || (c <= b && b <= a) {
        middle
    } else if (b <= a && a <= c) || (c <= a && a <= b) {
        first
    } else {
        last
    }
}

fn main() {
    let mut arr = [5, 3, 8, 1, 4, 7, 2, 6];

    quick_sort(&mut arr);

    println!("{:?}", arr);
}
```

### Quick_sort
-----------------
Функция `quick_sort(arr:&mut [i32])` в своих скобках принимает срез ([[Rust]]) массива внутри функции названного, как `arr` по мутабельной ссылке `&mut` (про мутабельность в rust [[Rust]]), внутри квадрат скобок пишем о типе массива (т.е. тип элементов массива) `[i32]` 

Здесь тоже сначало проверка `if` на пустой/массив с одним элементом. Потом создается опорный (про `partition` далее), который делит массив на два среза (до `pivot` и после) в рекурсивной функции `quick_sort`. 

Кстати говоря, `quick_sort` вызывается два раза, чтобы отсортировать два среза массива (до `pivot` и после `pivot`). Рекурсия здесь нужна, чтобы несколько раз вызвать `partition(arr)`

-----------------
### Partition
-------------------------
Функция `partition` принимает в своих скобках ссылку на массив, но в данном коде ссылка на массив сначало передается в `quick_sort(arr:&mut [i32])` потом через `let pivot =partition(arr)` передается в partition ( т.е. `arr` внутри `partition(arr)` хранит ссылку на массив, ведь мы его создали в `quick_sort` так `arr:&mut [i32]`)

```
+------------------------------+  
| quick_sort |  
|------------------------------|  
| arr: &mut [5, 3, 8, 1, 4] |  
+--------------+---------------+  
|  
|  
| let pivot = partition(arr);  
| (передаётся та же ссылка)  
v  
+------------------------------+  
| partition |  
|------------------------------|  
| arr: &mut [5, 3, 8, 1, 4] |  
+--------------+---------------+  
|  
| изменяет массив  
v  
[3, 1, 4, 5, 8]  
|  
| return 2  
v  
+------------------------------+  
| quick_sort |  
|------------------------------|  
| pivot = 2 |  
| arr = [3, 1, 4, 5, 8] |  
+------------------------------+
```

Так же результат работы (т.е. значение, которое мы возвращаем) переводим в тип `usize` ([[Rust]]), потому-что мы возвращаем индекс массива (смотреть объяснение далее)

Далее мы создаем `let len = arr.len()` (необязательная часть) и `let pivot_index =median_of_three(arr)` (смотреть объяснение далее, если в кратце более надежный способ чем делать индекс рандомным)

Далее создаем `let mut i=0` — это будет границей между обработанной частью массива и необработанной

```
[ < pivot | ещё не обработано ]
          ^
          i
```

Далее создаем цикл `for j in 0..len-1` в котором уже идет сортироваться от 0 до  `len-1` или `arr.len()-1` (-1 чтобы не выйти за границы массива)

Проверка `if` если элемент массива с индексом `j` меньше `pivot` выполняется код `arr.swap(i,j)` и `i+=1` ( обозначали, что элемент массива `j` меньше `pivot` поэтому оставили его в начале массива, под индексом 0 и увеличили `i` на единицу (т.е. элемент массива под индексом 0 был обработан идем дальше))

После того, как все было проверяно (т.е. на выходе из цикла) меняем местами `i` и последний элемент массива `len-1` (сделано, чтобы разделить массива на две части(смотреть в конкретном примере [[Примеры|пример]]))

### Median of three
-------------
Смысл — найти среднее значение в массиве.

Функция принимает массив через partition и переводит результат работы в `usize` (все тоже самое, что с partition)

Создается 

```rust
let first = 0;
let middle = arr.len() / 2;
let last = arr.len() - 1;
```

`first` — начальный индекс массива (поэтому 0), 
`middle` — средний индекс массива (поэтому делим на два)
`last` — последний индекс массива (arr.len()-1 значения последнего элемента массива)

```rust
let a = arr[first];
let b = arr[middle];
let c = arr[last];
```

Значение элементов массива передаются к `a b c`

Далее идет проверка действительно ли число является средним в массиве (можешь сам потрахаться с этими условиями я ебал объяснять)

```rust

        middle
} 
else if (b <= a && a <= c) || (c <= a && a <= b) {
        first
} 
else {
        last
}
```
