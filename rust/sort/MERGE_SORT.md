## Определение 
Merge Sort — метод сортировки слиянием. Суть проста, разделить массив на две части, отсортировать их как в bubble sort и потом объединить

---
## Rust

```rust
fn merge_sort(arr: &mut [i32]) {
    let len = arr.len();

    if len <= 1 {
        return;
    }

    let mid = len / 2;

    merge_sort(&mut arr[..mid]);
    merge_sort(&mut arr[mid..]);

    let mut merged = Vec::with_capacity(len);

    let (left, right) = arr.split_at(mid);

    let mut i = 0;
    let mut j = 0;

    while i < left.len() && j < right.len() {
        if left[i] <= right[j] {
            merged.push(left[i]);
            i += 1;
        } else {
            merged.push(right[j]);
            j += 1;
        }
    }

    while i < left.len() {
        merged.push(left[i]);
        i += 1;
    }

    while j < right.len() {
        merged.push(right[j]);
        j += 1;
    }

    arr.copy_from_slice(&merged);
}

fn main() {
    let mut arr = [5, 3, 8, 1, 4, 7];

    merge_sort(&mut arr);

    println!("{:?}", arr);
}
```

## До рекурсии

`fn merge_sort` принимает срез (slice [[Rust]]) по мутабельной ссылке, как и другие методы сортировки. Создается `let len=arr.len()` (необязательно).
Затем идет проверка `if`, если массив меньше или равен единицы сортировать его смысла нету.

---
## Рекурсия

Далее мы создаем середину `let mid = len/2`, по сути делим массив на два среза. `merge_sort(&mut arr[..mid])` и `merge_sort(&mut arr[mid..])` мы делаем рекурсию до того, как вся функция завершится таким образом разделенный массив делится повторно (рекурсивно). Так он делится примерно до того, как массив будет разделен до единицы элемента (т.е. пока не будет несколько массив состоящий из одного элемента)

И создается `let mut merged=Vec::with_capacity(len)` — массив хранящий в себе отсортированные элементы. (функция `with_capacity(len)` создает пустой массив с размером прописанными в скобках (вместо `len` может быть любое число, но в данном случае лучше просто прописать `len`))

`let (left, right) = arr.split_at(mid)` создаем (а точнее делим существующий массив) `left` и `right` по аргументу `mid` (функция `split_at` делит массив по аргументы в скобках, в данном случае по `mid`, который мы создавали ранее)

---
## Циклы While

Создается `j` и `i`, чтобы цикл `while` в принципе работал, даем значение ноль (потому-что массив начинается с нуля). 

`while i < left.len() && j < right.len()` — основной цикл, сраниваются элементы из двух массивов и по очередно добавляются в временный массив `merged`

```rust
if left[i] <= right[j] {
            merged.push(left[i]);
            i += 1;
        } else {
            merged.push(right[j]);
            j += 1;
        }
```

Здесь сраниваются элементы из массивов`left` и  `right`. Проверка такая если `left[i]` меньше `right[j]` то сначало добавляется `left[i]`, чтобы оно было в начале массива. В ином случае, сначало пушится `right[j]`  

---
Последующие циклы `while` созданы на тот случай если один массив полностью отсортировался (например массив `left[i]`), а другой нет. 

```rust
while j < right.len() {
        merged.push(right[j]);
        j += 1;
    }
```

Тут сравнивается неотсортированный элемент массива с его последним элементом массива, если неотсортированный элемент массива меньше последнего элемента то он естественного пушится раньше (потому-что сортируем мы в порядке возрастания, где последний элемент самый большой)

Тоже самое и для массива `left`

## Последний этап

`arr.copy_from_slice(&merged)` мы копируем все элементы из `merged` в `arr`, чтобы все изменения в нужном нам массиве (который мы вводили) вошли в силу. 

`&merged` передается по ссылке, потому-что это массив и потенциально может аллоцироваться в heap (что скорее всего ведь в данном примере `merged` это вектор (динамический массив)) и занимать места больше чем есть stack

Ну и еще потому-что это rust.
